## Cách thực hiện

- Dùng `rm -- "<path>"` → runtime Windows chuyển sang `mavis-trash` ⇒ **xoá khôi phục được** (Recycle Bin).
- Lọc media theo đuôi chuẩn **+ quét magic bytes** (RIFF/WAVE, ID3, ftyp, OggS, fLaC, MKV) để bắt file ẩn
  có đuôi sai (`.bak`, `.bak_bgm`, `.CU_BAN`, `.tmp`).
- `assets/` bị loại khỏi mọi lần quét — **không file nào trong `assets/` bị đụng tới**.
- Không dùng wildcard (launcher không mở rộng) và không dùng `Remove-Item` (xoá vĩnh viễn).
